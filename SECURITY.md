# Security policy

Please do not publish credentials, private student work, identifiable data, or restricted datasets in this repository. For a suspected repository vulnerability, open a private GitHub security advisory rather than posting exploit details in a public issue. Rotate any credential immediately if one is exposed.

The project uses pinned Python dependencies and GitHub workflow checks, but no checklist can guarantee complete security. Repository owners should enable secret scanning, push protection where available, Dependabot alerts, and code scanning in GitHub settings.
