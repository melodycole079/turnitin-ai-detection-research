# Responsible use

Do not use this benchmark to accuse a student, grade an assignment automatically, or make a disciplinary decision. A model prediction is a classification output conditioned on a dataset, not proof of authorship. Any concern should be reviewed with the writing process, drafts, citations, institutional policy, and a fair opportunity for contextual explanation.

Do not upload private student work without authorization. Keep raw datasets outside the public repository unless redistribution rights and privacy protections are clear. Remove names, student IDs, prompts that identify a class, and other personal information. Record provenance and license information before running an experiment.

The benchmark is also not a bypass tool. It does not provide instructions for hiding plagiarism or misrepresenting AI-generated work as independent writing.
