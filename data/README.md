# Data policy

The committed `sample/smoke.csv` file is a tiny synthetic fixture used only to test the pipeline. It is not a representative dataset and its metrics must not be used to estimate detector accuracy.

Research runs must use a dataset that the researcher is authorized to access and redistribute or keep locally. Document the dataset name, license, consent or provenance, label definitions, genre coverage, and any transformations in the benchmark report. Do not commit student submissions, personally identifying information, private course material, or restricted datasets. Put local raw data under `data/raw/`, which is ignored by Git.
